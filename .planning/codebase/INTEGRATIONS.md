# Integrations

## External Services
- **OpenRouter**: Unified API for model access (Nemotron, Gemma, GPT-OSS).
- **GitHub**: CI/CD (GitHub Actions), Issue tracking.

## Internal Components
- **EmbeddingService**: Singleton WASM-based embedding provider.
- **DALC (Diversity-Aware Layer Cake)**: Similarity-based proposer filtering.
- **RMoA (Refined Mixture of Agents)**: Iterative refinement with early exit.
- **Verifier Oracle**: Extrinsic validation layer (PoT, mathjs, Zod).
