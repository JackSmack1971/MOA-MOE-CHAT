# Product

## Register

product

## Users
Developers, AI researchers, and power users running local-first, high-efficiency MoE systems. Users value speed, transparency in the "expert reasoning" process, and technical control.

## Product Purpose
A local web UI for interacting with a Symbolic-MoE architecture. It must visualize the complex expert-graph topology and provide high-performance token streaming.

## Brand Personality
Precision, Orchestrated, Elite. The interface should feel like a high-end technical instrument—authoritative, dark, and zero-fluff.

## Anti-references
Generic SaaS cream dashboards. Avoid soft pastels, rounded bubbly buttons, and overly whitespace-heavy marketing layouts.

## Design Principles
- **Mechanical Transparency**: Never hide the plumbing. Show the expert weights, the adjacency matrix, and the token usage clearly.
- **High-Contrast Precision**: Use sharp edges, thin borders (1px), and vibrant accent colors (Cyan/Magenta) against deep charcoal/black.
- **Orchestrated Motion**: Animations should be purposeful and crisp, reflecting the "logic" of the agent graph.

## Accessibility & Inclusion
Standard web accessibility (keyboard nav, contrast). No specific requirements for reduced motion.
